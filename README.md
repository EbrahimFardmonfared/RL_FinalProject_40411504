# RL_FinalProject_40411504
طراحی و تحلیل عامل هوشمند در هزارتوی پویا (Dynamic Maze) با استفاده از الگوریتم‌های یادگیری تقویتی.

## معرفی پروژه
در این پروژه یک محیط هزارتوی پویا به صورت فرایند تصمیم‌گیری مارکف (MDP) مدل‌سازی شده است. عامل هوشمند باید با یادگیری سیاست بهینه، کلید را پیدا کرده و با عبور از درِ قفل‌شده به هدف برسد. الگوریتم‌های استفاده شده شامل Q-Learning ،Value Iteration و SARSA به همراه بخش انتقال یادگیری (Transfer Learning) می‌باشند.
