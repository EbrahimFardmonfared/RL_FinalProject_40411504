# 🚀 پروژه یادگیری تقویتی: عامل هوشمند در هزارتوی پویا (Dynamic Maze)

این مخزن شامل پیاده‌سازی جامع پروژه پایانی درس **یادگیری تقویتی (Reinforcement Learning)** دانشگاه صنعتی خواجه نصیرالدین طوسی است. در این پروژه، یک چارچوب کامل برای حل مسئله در یک محیط شبکه‌ای (Grid-world) پیچیده، پویا و غیرقطعی طراحی شده است. هدف اصلی، پیاده‌سازی، تحلیل و مقایسه الگوریتم‌های مختلف یادگیری تقویتی در برخورد با چالش‌هایی نظیر موانع متحرک، مکانیزم کلید-و-در، و انتقال دانش است.

---

## 🌟 ویژگی‌های کلیدی پروژه

### ۱. محیط پویای اختصاصی (`Dynamic Maze`)
* **طراحی هوشمند:** ابعاد نقشه و چیدمان بر اساس فرمول شماره دانشجویی (تولید نقشه ۱۵ در ۱۵) تنظیم شده است.
* **المان‌های محیط:** شامل دیوارهای ثابت، خانه‌های جریمه (Penalty)، کلید، درِ قفل‌دار، نقطه هدف (Goal) و موانع متحرک (Patrols).
* **عدم قطعیت (Stochasticity):** پیاده‌سازی احتمال لغزش عامل در حین حرکت (٪۸۰ حرکت صحیح، ٪۲۰ انحراف به طرفین).
* **شکل‌دهی پاداش (Reward Shaping):** قابلیت سوییچ بین پاداش‌های تُنُک (Sparse) و پاداش‌های شکل‌دهی‌شده برای تسریع همگرایی.
* **اعتبارسنجی قطعی (Validation):** استفاده از الگوریتم **BFS** برای تضمین وجود مسیر معتبر از مبدأ به کلید و از کلید به هدف در زمان تولید نقشه.

### ۲. پیاده‌سازی الگوریتم‌های پایه و پیشرفته
* **Value Iteration (مدل‌محور):** پیاده‌سازی دقیق معادله بلمن با استفاده از مدل احتمالاتی واقعی محیط جهت یافتن سیاست بهینه مطلق.
* **Q-Learning (مدل‌آزاد / Off-Policy):** یادگیری مبتنی بر تفاوت زمانی (TD) با پشتیبانی از استراتژی‌های کاهش اکتشاف ($\epsilon$-decay) به دو روش خطی و نمایی.
* **SARSA($\lambda$) (مدل‌آزاد / On-Policy):** پیاده‌سازی ردپای شایستگی (Eligibility Traces) از نوع Accumulating/Replacing با مقادیر مختلف لاندا ($\lambda$).

### ۳. انتقال یادگیری (Transfer Learning)
ارزیابی قابلیت تعمیم‌پذیری عامل یادگیرنده در محیط‌های تغییریافته (مشابه و کاملاً متفاوت) با ۴ سناریوی مختلف:
1. **آموزش از صفر (From Scratch):** خط مبنا بدون استفاده از دانش قبلی.
2. **انتقال کامل (Full Transfer):** انتقال مستقیم Q-Table مبدأ به مقصد.
3. **انتقال ضریب‌دار (Beta Transfer):** انتقال دانش با اعمال ضرایب تعدیل‌کننده ($\beta = 0.25, 0.5, 0.75$).
4. **انتقال انتخابی (Selective Transfer):** انتقال هوشمندانه دانشِ صرفاً خانه‌هایی که همسایگی محلی آن‌ها (خود خانه و ۴ خانه مجاور) در هر دو محیط یکسان باقی مانده است.

### ۴. رابط کاربری گرافیکی تعاملی (Pygame GUI)
* رندرینگ در لحظه (Real-time) از حرکت عامل، وضعیت در/کلید و مانع متحرک.
* نمایش گرافیکی جهت‌گیری سیاست‌ها (Policy Arrows) بر روی نقشه.
* داشبورد زنده برای پایش معیارهایی نظیر: شماره اپیزود، گام‌ها، نرخ موفقیت ۱۰۰ اجرای اخیر، و مقدار اپسیلون.

## 🚀 راهنمای اجرای بخش‌های مختلف

برای بررسی و بازتولید کامل نتایج پروژه، می‌توانید اسکریپت‌های زیر را به ترتیب اجرا کنید:

### ۱. اجرای رابط کاربری و شبیه‌سازی بصری (GUI)
برای مشاهده عملکرد عامل در محیط پویا به صورت تعاملی:
> python gui/app.py

**🎮 کلیدهای میانبر در حین اجرا:**
* `[SPACE]` : توقف/ادامه (Pause/Resume)
* `[M]` : تغییر حالت بین آموزش زنده و ارزیابی (Train / Eval)
* `[P]` : نمایش/مخفی‌سازی جهت سیاست‌های بهینه (Policy Arrows)
* `[1 / 2 / 3]` : تغییر محیط به ترتیب: مبدأ (Source) / مشابه (Similar) / متفاوت (Different)
* `[Q / S / V]` : سوییچ بین الگوریتم‌ها: Q-Learning / SARSA / Value Iteration
* `[+ / -]` : افزایش یا کاهش سرعت انیمیشن (FPS)
* `[R]` : ریست کردن اپیزود فعلی

### ۲. اجرای بنچمارک‌های الگوریتم‌های پایه
برای بررسی زمان همگرایی Value Iteration در برابر مقادیر مختلف گاما ($\gamma$) و همچنین مقایسه رفتار Q-Learning در کاهش خطی و نمایی اپسیلون:
> python main.py

*(تمامی نمودارها و داده‌ها در پوشه `results` ذخیره می‌شوند)*

### ۳. تحلیل سیاست‌ها و نقشه‌های حرارتی
برای تولید نقشه ارزش (Value Heatmap)، نقشه بازدید حالت‌ها (Visitation Heatmap) و استخراج نقاط اختلاف سیاست مدل‌آزاد در برابر Value Iteration:
> python experiments/analysis.py

### ۴. اجرای آزمایش‌های انتقال یادگیری (Transfer Learning)
برای اجرای خودکار هر ۴ سناریوی انتقال دانش بر روی هر دو محیط مشابه و متفاوت (تولید ۱۲ فایل CSV، نمودارهای عملکرد و نقشه‌های تفاوت Q-Table):
> python experiments/run_experiments.py
